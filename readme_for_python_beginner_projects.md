## 🚀 How to Run These Projects

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jhasonal640-design/Python-Beginner-Projects.git
   cd Python-Beginner-Projects
   ```

2. **Ensure Python 3 is installed:**
   ```bash
   python --version
   ```

3. **Run any script** (wrap filenames containing spaces in quotes):
   ```bash
   python "Quiz Game,1st Project.py"
   ```

> **Note:** For `Password Manager, 5.py`, make sure you have the `cryptography` library installed (`pip install cryptography`) if your script uses Fernet encryption. For `shortest path finder.py` on Windows, you may need `windows-curses` (`pip install windows-curses`).
